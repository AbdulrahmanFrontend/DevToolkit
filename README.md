# DevToolkit

A collection of reusable .NET Framework 4.8 libraries built to reduce repetitive code and provide shared components across desktop applications.

## Modules

- **DevToolkit.Core:** Result types, validation, guard clauses, and shared utilities.
- **DevToolkit.Data:** ADO.NET data access abstractions, query execution, object mapping, and SQL Server/SQLite providers.
- **DevToolkit.Logging:** File, console, event, and composite logging.
- **DevToolkit.Infrastructure:** Database initialization, backup, configuration, and application folder management.
- **DevToolkit.Security:** Password hashing utilities.
- **DevToolkit.BaseWinForms:** Reusable WinForms controls and UI components.
- **DevToolkit.BaseWPF:** Shared WPF controls, commands, navigation, and dialog services.

## Technology Stack

- C#
- .NET Framework 4.8
- ADO.NET
- SQL Server
- SQLite
- Windows Forms
- WPF

DevToolkit is intended to support existing .NET Framework desktop applications and centralize reusable functionality rather than duplicate it across projects.
